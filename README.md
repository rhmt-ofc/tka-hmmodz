## 🌟 Filosofi & Bahasa Desain: Dark Neobrutalism
TKAORA v2.5 mengusung bahasa visual **Dark Neobrutalism** berenergi tinggi yang memadukan ketegasan estetika retro-tech dan kenyamanan belajar maksimal:
- **Estetika Taktil & Fokus:** Menggunakan garis batas tebal 2.5px solid hitam, bayangan jatuh kaku (*hard offset shadows* tanpa blur: `4px 4px 0px #000`), dan respon klik mekanikal taktil (`:active { transform: translate(2px, 2px); }`).
- **High-Voltage Cyber Palette:** Aksen warna kontras tinggi: *Cyber Lemon* (`#ffe600`), *Neon Pink* (`#ff2a6d`), *Mint Acid* (`#05ffa1`), *Electric Violet* (`#7952ff`), dan *Cyan Hyper* (`#00f0ff`).
- **Blueprint Dot Matrix Canvas:** Latar belakang dark slate bertekstur dot-grid presisi untuk nuansa instrumen laboratorium sains modern.

## 🎯 Soal Autentik Diekstrak Langsung dari 14 PDF Resmi TKA 2025
Bukan soal sintetis buatan AI! Bank soal TKAORA v2.5 memuat **20 butir soal asli** yang diekstraksi langsung dari dokumen kurikulum resmi TKA 2025:
1. **Bahasa Indonesia (Wajib):** Wacana Tradisi Buwuhan Surabaya & Evaluasi Kritis Cerpen *"Layur, Teruslah Berlayar"* karya Anang YB.
2. **Bahasa Inggris (Wajib):** Narrative Fable *"The Lion and The Mouse"* (Inference & Moral Message) dan Expository Text *"Pomodoro Technique"*.
3. **Matematika (Wajib):** Model Linear Pemanasan Global $y = 0,02x - 39,9$ (Pencarian tahun $x$ saat suhu mencapai $0,7$ °C) dan penyederhanaan eksponen pecahan.
4. **Matematika (Pilihan):** Gradien Garis Singgung Kurva Parabola $f(x) = 2x^2 - 3x + 1$ di titik $x = 2$ ($m = 5$).
5. **Biologi (Pilihan):** Interaksi Komponen Ekosistem Parasitisme Lintah pada Mamalia dan 4 Tahap Respirasi Aerob Glukosa.
6. **Ekonomi (Pilihan):** Biaya Peluang (*Opportunity Cost*) Safia lulusan S1 dan Efek Kenaikan UMP 2025 Sebesar 6,5% terhadap Pergeseran Kurva Penawaran PT Adiwastra Jaya.
7. **Fisika (Pilihan):** Vektor Gerak Relatif Feri Menyeberang Arus Sungai/Laut ($v = \sqrt{13^2 - 5^2} = 12$ km/jam) dan Pertemuan Dua Benda (GLB vs GLBB).
8. **Kimia (Pilihan):** Stoikiometri Persen Massa Karbon pada Asam Amino Alanin ($C_3H_7NO_2$) dan Bilangan Avogadro Partikel Polutan Gas $SO_2$.
9. **Geografi (Pilihan):** Biogeografi Garis Wallace & Weber serta Konservasi Flora Kawasan Peralihan Wallacea.
10. **Sosiologi (Pilihan):** Kontak Sosial Sekunder Bermedia Daring pada Masa Pandemi dan Multikulturalisme Sumpah Pemuda 1928.
11. **Pendidikan Pancasila & Sejarah:** Bela Negara Pelajar Era Keterbukaan Informasi dan Motif Kedatangan Bangsa Eropa (Gold, Glory, Gospel).

## 🧪 Studio Belajar Interaktif (Interactive Learning Studio)
Setiap modul dari 14 mata pelajaran dilengkapi dengan modal belajar 4 mode:
- 🧠 **Flashcard 3D:** Kartu hafalan konsep interaktif dengan efek putar 3D, memuat definisi esensial, peringatan **Jebakan Soal**, trik memori, dan pelacak status *"Sudah Paham"* vs *"Perlu Review"*.
- ⚡ **Lab Simulator Terapan:** Simulator interaktif berdasar rumus asli, seperti slider tahun pemanasan global, kalkulator gradien turunan parabola, kalkulator kecepatan kapal vs arus laut, dan pemilih massa molar stoikiometri alanin.
- 🎯 **Kuis Checkpoint Kilat:** Uji retensi instan 2–3 butir soal di dalam materi dengan indikator visual langsung (Hijau jika benar, Merah jika salah) beserta penjelasan kunci.
- 📄 **Dokumen PDF & Smart Scratchpad:** Pembacaan dokumen resmi in-app berdampingan dengan kolom memo rumus pribadi yang tersimpan otomatis di peramban (`localStorage`).

## 🛠️ Instalasi & Menjalankan Lokal

```bash
# 1. Klon repositori
git clone https://github.com/rhmt-ofc/tka-hmmodz.git
cd tka-hmmodz

# 2. Pasang dependensi
bun install  # atau npm install

# 3. Jalankan server lokal
bun run app.js  # atau node app.js
```
Akses di peramban: `http://localhost:8080` (atau port yang ditentukan).
