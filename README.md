# ⚡ TKAORA v2.5 — Ruang Belajar & Latihan TKA SMA

> **Platform Belajar Mandiri Zen & Anti-Stres untuk Persiapan Tes Kemampuan Akademik (TKA) SMA.**  
> Dikembangkan dengan presisi oleh **HMMODZ (Rohmatulloh)**.

---

## 🌟 Filosofi & Konsep
TKAORA dibangun dengan pendekatan **Calm Ed-Tech**:
- **Bebas Stres:** Tanpa sistem peringkat (*no toxic leaderboard*), tanpa poin adu gengsi.
- **Fokus Pemahaman:** 14 modul PDF kurikulum resmi terintegrasi di dalam web (*in-app distraction-free reader*).
- **Latihan Cerdas:** 15 soal penalaran interaktif dengan opsi taktil, tombol ragu-ragu, dan pembacaan wacana split-view.
- **Latih Ulang Soal Salah:** Fitur unggulan satu klik untuk mengulang khusus nomor yang keliru agar siswa bisa langsung menaklukkan titik lemahnya.
- **Rumus Kilat 5 Menit:** Ringkasan rumus kunci dan strategi penalaran praktis sebelum ujian.
- **Estetika Crafted Software:** Mengadopsi bahasa desain Linear & Raycast (Dark/Light mode switch, border halus, micro-shadows, dan bebas AI slop).

---

## 🚀 Fitur Unggulan (Roadmap ngodingpakeai.com)

### 📌 FASE 1: Fondasi Interaktif & Navigasi
- **Katalog 14 Modul:** Filter Rumpun (*Literasi & Bahasa*, *Numerasi & Sains*, *Sosial & Humaniora*) dan filter Wajib/Pilihan.
- **Pencarian Instan:** Shortcut keyboard `/` untuk fokus cepat ke kolom pencarian materi.
- **Soal Interaktif:** Opsi A–D taktil dengan navigasi kapsul horizontal yang responsif di ponsel.

### 📌 FASE 2: Mesin Latihan & Pembahasan Mendalam
- **Pilihan Mode:** *Mode Santai (Zen)* tanpa batas waktu atau *Mode Simulasi Waktu (15 Menit)*.
- **Pintasan Keyboard:** Tekan `A`, `B`, `C`, `D` atau `1`, `2`, `3`, `4` untuk menjawab, panah `←` / `→` untuk berpindah nomor, dan `F` untuk menandai ragu-ragu.
- **Pembahasan Mendalam:** Ulasan komprehensif konsep kunci dan analisis jebakan soal.
- **Retest Salah Saja:** Fitur saring instan untuk menguji ulang soal yang salah.

### 📌 FASE 3: Perpustakaan PDF & Personalisasi
- **In-App PDF Viewer:** Membaca dokumen langsung di dalam aplikasi tanpa aplikasi pihak ketiga.
- **Lembar Catatan Saku (Scratchpad):** Kolom memo pribadi yang otomatis tersimpan di perangkat (`localStorage`).
- **Cadangan Data Mandiri:** Fitur Ekspor & Impor JSON agar siswa bisa memindahkan catatan ke perangkat lain tanpa perlu akun rumit.

### 📌 FASE 4: Retensi & Nilai Tambah
- **Rumus Kilat:** Ringkasan formula matematika, sains, dan literasi.
- **Indikator Kemajuan Sirkular:** Cincin kemajuan belajar di Beranda untuk memantau modul yang telah diselesaikan.

## 🛠️ Menjalankan Lokal

```bash
bun install  # atau npm install
node app.js
```
Buka browser di `http://localhost:8080`.

## 🌐 Deploy ke Vercel

Proyek ini siap dideploy langsung ke **Vercel**:
1. Push repositori ke GitHub.
2. Impor proyek di Dashboard Vercel.
3. Vercel akan otomatis mengenali runtime Node.js/Express melalui `vercel.json`.
